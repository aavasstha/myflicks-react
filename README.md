# 🎬 My Mlicks - Movie Discovery App

Welcome to **My Mlicks**, a movie discovery application!  
Find trending movies, search for your favorites.

## 🚀 Live Demo
🔗 **Frontend (React):** [https://myflicksv2.netlify.app/]
🔗 **Backend (Express):** [https://myflicks-react.onrender.com/]

---

## 🛠️ Tech Stack

### **Frontend (React)**
- Vite + React.js ⚛️
- Tailwind CSS 🎨
- Fetch API for movie data 🎬

### **Backend (Express)**
- Node.js + Express.js 🛠️
- PostgreSQL (Supabase) 🗄️
- JWT Authentication 🔑


### **Deployment**
- **Frontend:** Netlify 🌍
- **Backend:** Render ⚡
- **Database:** Supabase PostgreSQL 🗃️
